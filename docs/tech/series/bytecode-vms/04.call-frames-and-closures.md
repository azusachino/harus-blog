## Bytecode VMs 04: Call Frames, Activation Records, and Lexical Closures

Functions are the primary unit of modularity in programming languages. However, transitioning from a flat script to a runtime supporting arbitrary function calls, recursion, and first-class lexical closures requires a fundamental architectural elevation: the **Call Stack** and **Activation Records (Call Frames)**.

When a function executes, where do its local variables live? How does `return` know which instruction in the caller to resume? And what happens when an inner function captures a local variable from an outer function, but outlives the outer function's execution?

---

### 1. The Anatomy of an Activation Record (Call Frame)

An activation record represents the private execution context of a single function invocation. In production virtual machines (such as CPython's `_PyInterpreterFrame` or Lua's `CallInfo`), each frame encapsulates five critical components:

```text
+-------------------------------------------------------+
|  prev_frame (pointer to caller's CallFrame)           |
+-------------------------------------------------------+
|  code_object (bytecode array, constants, metadata)    |
+-------------------------------------------------------+
|  pc (program counter / instruction pointer)           |
+-------------------------------------------------------+
|  localsplus[] (contiguous array of local variable slots)|
+-------------------------------------------------------+
|  cells[] (pointers to shared HeapCell boxes for closures)
+-------------------------------------------------------+
|  stacktop (pointer to the evaluation stack slice)     |
+-------------------------------------------------------+
```

#### Frame Allocation Strategies

1. **Heap-Allocated Frames (Historical CPython < 3.11)**: Every function call allocated a `PyFrameObject` on the system heap via `PyObject_GC_New`. While simple, allocating 100+ bytes from the heap on every function call caused high memory allocator pressure. CPython mitigated this with a free list (`frame_free_list`), recycling up to 200 deallocated frames.
2. **Contiguous Chunk / Array Frames (CPython 3.11+, Lua)**: Modern interpreters allocate a large pre-sized memory buffer (e.g. 1 MB to 8 MB) per thread. Function calls push frames contiguously onto this runtime call stack by bumping a stack pointer (`thread->current_frame++`), reducing call overhead to near zero.

### 2. Variable Scope Resolution: LEGB in Hardware Terms

Dynamic languages like Python define a strict scoping hierarchy: **Local $\to$ Enclosing $\to$ Global $\to$ Built-in (LEGB)**.

In bytecode, these scopes translate to fundamentally different access mechanisms:

| Scope | Opcode | Data Structure & Algorithm | Complexity |
|---|---|---|---|
| **Local** | `LOAD_FAST index` | Contiguous array offset: `frame->localsplus[index]` | $\mathcal{O}(1)$ (1 memory load) |
| **Enclosing (Cell)** | `LOAD_DEREF index` | Double pointer dereference: `*frame->cells[index]->value` | $\mathcal{O}(1)$ (2 memory loads) |
| **Global** | `LOAD_GLOBAL name` | Hash table lookup in module `globals_dict` | $\mathcal{O}(1)$ average (hash probe) |
| **Built-in** | Fallback | Secondary hash table lookup in `builtins_dict` | $\mathcal{O}(1)$ average (fallback probe) |

Notice the performance asymmetry: reading a local variable (`LOAD_FAST`) takes ~1 CPU clock cycle. Reading an unqualified global variable requires computing a string hash, probing a hash table bucket, comparing keys, and checking for collisions—consuming 10 to 30 clock cycles.

---

### 3. The Upward Funarg Problem and Heap Cells

In languages with first-class functions (Python, JavaScript, Lua, Scheme), a function can return an inner function:

```text
def make_counter(start):
    count = start
    def increment():
        nonlocal count
        count += 1
        return count
    return increment

c = make_counter(10)
c()  # Returns 11
c()  # Returns 12
```

In standard C or Fortran, local variables live on the native CPU call stack. When `make_counter` returns, its stack frame is popped and overwritten. If `increment` attempted to access `count` on `make_counter`'s popped stack frame, it would read corrupted garbage memory (the classic **Dangling Pointer** bug).

This is known as the **Upward Funarg (Functional Argument) Problem**: an enclosing function's activation record must logically outlive its return when captured by a closure escaping upward.

#### The Solution: Heap-Allocated Cell Objects

Rather than storing `count` directly inside `make_counter`'s local stack slot, the compiler detects that `count` is captured by an inner scope.

1. At frame initialization, the runtime allocates a **`Cell` object** on the garbage-collected heap:

   ```text
   HeapCell {
       refcnt: 2,
       value: 10
   }
   ```

2. Both `make_counter` (via `STORE_DEREF`) and `increment` (via `LOAD_DEREF` / `STORE_DEREF`) hold a pointer to this identical `HeapCell` box.
3. When `make_counter` returns, its activation record is deallocated, but its reference to `HeapCell` is dropped while `increment`'s function object retains its reference. The shared variable remains alive on the heap!

### 4. Verification Lab: Multi-Frame VM with Recursion and Lexical Closures

The following self-contained Python lab implements a complete multi-frame virtual machine. It features:

- A dynamic **Call Stack** of `CallFrame` objects with maximum recursion depth protection.
- Function objects (`FunctionObject`) containing isolated code objects and captured closure cell environments.
- Execution of **Recursive Factorial** (`factorial(5) == 120`) validating activation record pushing and unwinding.
- Execution of **Lexical Closures with Shared Heap Cells** validating that inner functions correctly mutate outer escaping variables across independent invocations.

```python
"""
Bytecode VMs Lab 04 - Call Frames, Activation Records, and Lexical Closures
Tests multi-frame function calls, recursion depth unwinding, and heap cell closures.
"""

from typing import List, Tuple, Any, Dict, Optional
from enum import Enum, auto

class Op(Enum):
    LOAD_CONST = auto()
    LOAD_FAST = auto()
    STORE_FAST = auto()
    LOAD_DEREF = auto()   # Read from closure cell
    STORE_DEREF = auto()  # Write to closure cell
    MAKE_CELL = auto()    # Promote local slot into heap cell
    MAKE_FUNCTION = auto()
    CALL_FUNCTION = auto()
    RETURN_VALUE = auto()
    BINARY_ADD = auto()
    BINARY_SUB = auto()
    BINARY_MUL = auto()
    COMPARE_EQ = auto()
    JUMP_IF_FALSE = auto()
    JUMP_ABSOLUTE = auto()

# A shared heap cell for escaping closure variables
class HeapCell:
    def __init__(self, value: Any = None):
        self.value = value

    def __repr__(self):
        return f"Cell({self.value!r})"

class CodeObject:
    def __init__(self, name: str, bytecode: List[Tuple[Op, Any]], consts: List[Any], varnames: List[str]):
        self.name = name
        self.bytecode = bytecode
        self.consts = consts
        self.varnames = varnames

class FunctionObject:
    def __init__(self, code: CodeObject, closure_cells: List[HeapCell]):
        self.code = code
        self.closure_cells = closure_cells  # Cells captured from enclosing scope

class CallFrame:
    def __init__(self, fn: FunctionObject, args: List[Any], prev_frame: Optional['CallFrame']):
        self.fn = fn
        self.prev_frame = prev_frame
        self.pc = 0
        self.stack: List[Any] = []
        # Preallocate local variable slots
        self.locals: List[Any] = [None] * max(len(fn.code.varnames), len(args))
        for i, arg in enumerate(args):
            self.locals[i] = arg
        # Preallocate cell slots for variables promoted to heap cells
        self.cells: List[HeapCell] = list(fn.closure_cells)

class VirtualMachine:
    MAX_RECURSION_DEPTH = 1000

    def __init__(self):
        self.frame_stack: List[CallFrame] = []
        self.call_depth = 0

    def push_frame(self, fn: FunctionObject, args: List[Any]) -> CallFrame:
        if self.call_depth >= self.MAX_RECURSION_DEPTH:
            raise RecursionError(f"Maximum recursion depth {self.MAX_RECURSION_DEPTH} exceeded")
        prev = self.frame_stack[-1] if self.frame_stack else None
        frame = CallFrame(fn, args, prev)
        self.frame_stack.append(frame)
        self.call_depth += 1
        return frame

    def pop_frame(self) -> CallFrame:
        self.call_depth -= 1
        return self.frame_stack.pop()

    def run(self, top_fn: FunctionObject, initial_args: List[Any]) -> Any:
        self.push_frame(top_fn, initial_args)

        while self.frame_stack:
            frame = self.frame_stack[-1]
            code = frame.fn.code

            if frame.pc >= len(code.bytecode):
                # Implicit return None if frame runs off the end
                ret_val = None
                self.pop_frame()
                if self.frame_stack:
                    self.frame_stack[-1].stack.append(ret_val)
                else:
                    return ret_val
                continue

            op, arg = code.bytecode[frame.pc]
            frame.pc += 1

            if op == Op.LOAD_CONST:
                frame.stack.append(code.consts[arg])
            elif op == Op.LOAD_FAST:
                frame.stack.append(frame.locals[arg])
            elif op == Op.STORE_FAST:
                frame.locals[arg] = frame.stack.pop()
            elif op == Op.MAKE_CELL:
                # Promote local slot [arg] to a HeapCell
                initial_val = frame.locals[arg]
                cell = HeapCell(initial_val)
                frame.cells.append(cell)
            elif op == Op.LOAD_DEREF:
                # Read from cell [arg]
                cell = frame.cells[arg]
                frame.stack.append(cell.value)
            elif op == Op.STORE_DEREF:
                # Write to cell [arg]
                val = frame.stack.pop()
                frame.cells[arg].value = val
            elif op == Op.BINARY_ADD:
                b = frame.stack.pop()
                a = frame.stack.pop()
                frame.stack.append(a + b)
            elif op == Op.BINARY_SUB:
                b = frame.stack.pop()
                a = frame.stack.pop()
                frame.stack.append(a - b)
            elif op == Op.BINARY_MUL:
                b = frame.stack.pop()
                a = frame.stack.pop()
                frame.stack.append(a * b)
            elif op == Op.COMPARE_EQ:
                b = frame.stack.pop()
                a = frame.stack.pop()
                frame.stack.append(a == b)
            elif op == Op.JUMP_IF_FALSE:
                cond = frame.stack.pop()
                if not cond:
                    frame.pc = arg
            elif op == Op.JUMP_ABSOLUTE:
                frame.pc = arg
            elif op == Op.MAKE_FUNCTION:
                # arg is the code object; stack has captured cell references
                func_code: CodeObject = code.consts[arg]
                captured_cells = list(frame.cells)
                fn_obj = FunctionObject(func_code, captured_cells)
                frame.stack.append(fn_obj)
            elif op == Op.CALL_FUNCTION:
                # arg is argc
                argc = arg
                args = [frame.stack.pop() for _ in range(argc)][::-1]
                callee_fn: FunctionObject = frame.stack.pop()
                self.push_frame(callee_fn, args)
            elif op == Op.RETURN_VALUE:
                ret_val = frame.stack.pop()
                self.pop_frame()
                if self.frame_stack:
                    self.frame_stack[-1].stack.append(ret_val)
                else:
                    return ret_val

        return None

def run_lab():
    vm = VirtualMachine()

    # -------------------------------------------------------------
    # Test 1: Recursive Factorial
    # def fact(n):
    #     if n == 1: return 1
    #     return n * fact(n - 1)
    # -------------------------------------------------------------
    # Bytecode for factorial:
    # 0: LOAD_FAST 0 (n)
    # 1: LOAD_CONST 0 (1)
    # 2: COMPARE_EQ
    # 3: JUMP_IF_FALSE 6
    # 4: LOAD_CONST 0 (1)
    # 5: RETURN_VALUE
    # 6: LOAD_FAST 0 (n)
    # 7: LOAD_FAST 1 (self/fact reference)
    # 8: LOAD_FAST 0 (n)
    # 9: LOAD_CONST 0 (1)
    # 10: BINARY_SUB
    # 11: CALL_FUNCTION 1 (fact(n-1))
    # 12: BINARY_MUL
    # 13: RETURN_VALUE
    fact_code = CodeObject(
        name="fact",
        bytecode=[
            (Op.LOAD_FAST, 0),        # n
            (Op.LOAD_CONST, 0),       # 1
            (Op.COMPARE_EQ, None),
            (Op.JUMP_IF_FALSE, 6),
            (Op.LOAD_CONST, 0),       # return 1
            (Op.RETURN_VALUE, None),
            (Op.LOAD_FAST, 0),        # n (save on stack for later multiplication)
            (Op.LOAD_FAST, 1),        # fact (callee function object)
            (Op.LOAD_FAST, 0),        # n
            (Op.LOAD_CONST, 0),       # 1
            (Op.BINARY_SUB, None),    # n - 1 (arg 1)
            (Op.LOAD_FAST, 1),        # fact (arg 2: pass self for recursion)
            (Op.CALL_FUNCTION, 2),    # fact(n-1, fact)
            (Op.BINARY_MUL, None),    # n * fact(n-1)
            (Op.RETURN_VALUE, None),
        ],
        consts=[1],
        varnames=["n", "fact_fn"]
    )
    fact_fn = FunctionObject(fact_code, closure_cells=[])
    # Compute fact(5) -> 120
    res_fact = vm.run(fact_fn, [5, fact_fn])
    assert res_fact == 120
    assert vm.call_depth == 0  # All frames cleanly popped

    # -------------------------------------------------------------
    # Test 2: Lexical Closure with Shared Heap Cell
    # def make_counter(start):
    #     count = start
    #     def increment():
    #         count = count + 1
    #         return count
    #     return increment
    # -------------------------------------------------------------
    # Inner increment() bytecode:
    # 0: LOAD_DEREF 0 (read cell count)
    # 1: LOAD_CONST 0 (1)
    # 2: BINARY_ADD
    # 3: STORE_DEREF 0 (write cell count)
    # 4: LOAD_DEREF 0
    # 5: RETURN_VALUE
    inc_code = CodeObject(
        name="increment",
        bytecode=[
            (Op.LOAD_DEREF, 0),
            (Op.LOAD_CONST, 0),
            (Op.BINARY_ADD, None),
            (Op.STORE_DEREF, 0),
            (Op.LOAD_DEREF, 0),
            (Op.RETURN_VALUE, None)
        ],
        consts=[1],
        varnames=[]
    )

    # Outer make_counter(start) bytecode:
    # 0: LOAD_FAST 0 (start)
    # 1: STORE_FAST 1 (count)
    # 2: MAKE_CELL 1 (promote count to cell 0)
    # 3: MAKE_FUNCTION 0 (inner inc_code with cell 0)
    # 4: RETURN_VALUE
    outer_code = CodeObject(
        name="make_counter",
        bytecode=[
            (Op.LOAD_FAST, 0),
            (Op.STORE_FAST, 1),
            (Op.MAKE_CELL, 1),
            (Op.MAKE_FUNCTION, 0),
            (Op.RETURN_VALUE, None)
        ],
        consts=[inc_code],
        varnames=["start", "count"]
    )
    outer_fn = FunctionObject(outer_code, closure_cells=[])

    # Run outer: returns the inner increment function object
    counter_closure: FunctionObject = vm.run(outer_fn, [100])
    assert isinstance(counter_closure, FunctionObject)
    assert len(counter_closure.closure_cells) == 1
    assert counter_closure.closure_cells[0].value == 100

    # Execute counter_closure() call 1 -> returns 101
    val1 = vm.run(counter_closure, [])
    assert val1 == 101
    assert counter_closure.closure_cells[0].value == 101

    # Execute counter_closure() call 2 -> returns 102
    val2 = vm.run(counter_closure, [])
    assert val2 == 102
    assert counter_closure.closure_cells[0].value == 102

    # Execute counter_closure() call 3 -> returns 103
    val3 = vm.run(counter_closure, [])
    assert val3 == 103
    assert counter_closure.closure_cells[0].value == 103

    print(f"Factorial(5) = {res_fact} (Recursive frames verified)")
    print(f"Counter closure sequence: [{val1}, {val2}, {val3}] (Shared HeapCell verified)")
    print("Bytecode VM Lab 04 passed: Call frames, recursion, and lexical closures verified.")

if __name__ == "__main__":
    run_lab()
```
