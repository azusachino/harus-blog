## Bytecode VMs 01: Lexing, AST Parsing, and Bytecode Generation

Virtual machines operate on dense, linear sequences of instructions called **bytecode**. Unlike source code, which exists as nested character strings, and unlike high-level Abstract Syntax Trees (ASTs), which exist as recursive pointer graphs in memory, bytecode is designed for one primary goal: **fast, cache-friendly instruction decoding on modern CPUs**.

Tree-walking interpreters (such as early implementations of Ruby, PHP, and experimental toy interpreters) evaluate programs by recursively calling an `eval(node)` function across AST nodes. While conceptually clean, tree-walking incurs devastating performance penalties:

1. **Pointer chasing**: Each AST child node sits at an arbitrary heap address, causing frequent CPU L1/L2 data cache misses.
2. **Call stack churn**: Evaluating deeply nested binary expressions consumes native C stack frames.
3. **Dispatch overhead**: Recursive function calls impose register saving, parameter passing, and return handling on every syntactic step.

A bytecode compiler solves these bottlenecks by linearizing the AST into a flat byte array, pre-resolving variable names into numeric array indices, and hoisting literals into an immutable constant table.

---

### 1. The Compilation Pipeline

The journey from source text to virtual machine execution flows through four structured phases:

<Archify src="./diagrams/compiler-frontend-to-bytecode.workflow.json" />

1. **Lexical Scanning (Lexer)**: Consumes raw UTF-8 characters and emits a stream of typed tokens (`TOKEN_IDENT`, `TOKEN_NUMBER`, `TOKEN_PLUS`, `TOKEN_ASSIGN`).
2. **Syntactic Parsing (Pratt Parser)**: Consumes tokens and constructs an Abstract Syntax Tree using operator-precedence binding powers.
3. **Semantic Scope Analysis**: Traverses the AST to classify variables into local stack slots, global lookups, and closure cells.
4. **Bytecode Linearization**: Emits sequential opcodes (`LOAD_CONST`, `BINARY_ADD`, `STORE_FAST`), calculates relative jump targets, and outputs a compiled `CodeObject`.

---

### 2. Scanning: Characters to Tokens

A lexer maintains an input cursor and classifies substrings into lexical tokens with coordinate spans. Consider parsing `total = count + 42`:

```text
Input text:   t o t a l   =   c o u n t   +   4 2
Tokens:       [IDENT: total] [ASSIGN] [IDENT: count] [PLUS] [NUMBER: 42] [EOF]
```

Tokens preserve source spans (line and column offsets) for diagnostic error reporting, but strip whitespace and comments that carry no execution semantics.

---

### 3. Parsing: Pratt Parsing with Binding Power

While grammars can be parsed using recursive descent or parser generators, **Pratt parsing (Top-Down Operator Precedence)** is the industry standard for expression-heavy programming languages (used extensively in Rust's compiler, Lua, and modern dynamic language frontends).

Each operator is assigned two numbers: **left binding power** and **right binding power**:

| Operator | Left Binding Power | Right Binding Power | Associativity |
|---|---|---|---|
| Assignment (`=`) | 2 | 1 | Right-associative |
| Addition (`+`), Subtraction (`-`) | 5 | 6 | Left-associative |
| Multiplication (`*`), Division (`/`) | 7 | 8 | Left-associative |
| Unary (`-`, `!`) | - | 9 | Prefix |

Because addition's right binding power (6) is lower than multiplication's left binding power (7), the parser naturally binds `a + b * c` as `a + (b * c)` without backtracking or ambiguous grammar specifications.

---

### 4. Scope Analysis & Variable Classification

In dynamic languages, how a variable is accessed dictates its bytecode instruction. Dynamic virtual machines like CPython split variable access into distinct speed tiers:

1. **Local Variables (`LOAD_FAST` / `STORE_FAST`)**: In functions where variables are statically bounded, the compiler assigns each name a fixed index (`slot 0`, `slot 1`). At runtime, access is a single pointer offset from the frame base (`frame->localsplus[index]`), executing in a single CPU instruction.
2. **Global Variables (`LOAD_GLOBAL` / `STORE_GLOBAL`)**: Module-level variables are unresolved at compile time. The VM must perform a hash table lookup in the global namespace dictionary.
3. **Free & Cell Variables (`LOAD_DEREF` / `STORE_DEREF`)**: Variables captured by inner closures escape the call stack and live inside heap-allocated `Cell` boxes.

---

### 5. Linearizing AST to Bytecode: The Post-Order Traversal

Emitting bytecode from an expression AST follows a post-order traversal: child operands are compiled before the operator that consumes them.

For the expression `(a + 10) * b`:

```text
      [*]
     /   \
   [+]    [b]
  /   \
[a]  [10]
```

1. Compile left child:
   - Emit `LOAD_NAME 'a'`
   - Emit `LOAD_CONST 10`
   - Emit `BINARY_ADD`
2. Compile right child:
   - Emit `LOAD_NAME 'b'`
3. Emit root operator:
   - Emit `BINARY_MUL`

The resulting instruction array is completely linear:

```text
Offset  Opcode         Operand
0000    LOAD_NAME      0 ('a')
0002    LOAD_CONST     0 (10)
0004    BINARY_ADD     0
0006    LOAD_NAME      1 ('b')
0008    BINARY_MUL     0
0010    RETURN_VALUE   0
```

### 6. Verification Lab: Lexer, Pratt Parser, and Bytecode Emitter

The following self-contained Python lab implements a complete compiler frontend: a token scanner, a Pratt operator-precedence expression parser, a scope analyzer, and a bytecode linearizer producing an executable `CodeObject`.

```python
"""
Bytecode VMs Lab 01 - Lexing, Pratt Parsing, and Bytecode Linearization
Tests token scanning, operator precedence parsing, and linear bytecode emission.
"""

from typing import List, Tuple, Any, Dict, Optional
from enum import Enum, auto

class TokenType(Enum):
    NUMBER = auto()
    IDENT = auto()
    PLUS = auto()
    MINUS = auto()
    STAR = auto()
    SLASH = auto()
    ASSIGN = auto()
    LPAREN = auto()
    RPAREN = auto()
    EOF = auto()

class Token:
    def __init__(self, typ: TokenType, value: Any, pos: int):
        self.typ = typ
        self.value = value
        self.pos = pos

    def __repr__(self) -> str:
        return f"Token({self.typ.name}, {self.value!r})"

class Lexer:
    def __init__(self, text: str):
        self.text = text
        self.pos = 0

    def next_token(self) -> Token:
        while self.pos < len(self.text) and self.text[self.pos].isspace():
            self.pos += 1
        if self.pos >= len(self.text):
            return Token(TokenType.EOF, None, self.pos)

        ch = self.text[self.pos]
        start = self.pos

        if ch.isdigit():
            val = 0
            while self.pos < len(self.text) and self.text[self.pos].isdigit():
                val = val * 10 + int(self.text[self.pos])
                self.pos += 1
            return Token(TokenType.NUMBER, val, start)

        if ch.isalpha() or ch == '_':
            buf = []
            while self.pos < len(self.text) and (self.text[self.pos].isalnum() or self.text[self.pos] == '_'):
                buf.append(self.text[self.pos])
                self.pos += 1
            return Token(TokenType.IDENT, "".join(buf), start)

        single_chars = {
            '+': TokenType.PLUS,
            '-': TokenType.MINUS,
            '*': TokenType.STAR,
            '/': TokenType.SLASH,
            '=': TokenType.ASSIGN,
            '(': TokenType.LPAREN,
            ')': TokenType.RPAREN,
        }
        if ch in single_chars:
            self.pos += 1
            return Token(single_chars[ch], ch, start)

        raise SyntaxError(f"Unexpected character {ch!r} at pos {self.pos}")

# AST Node Hierarchy
class ASTNode:
    pass

class NumberNode(ASTNode):
    def __init__(self, val: int):
        self.val = val

class VarNode(ASTNode):
    def __init__(self, name: str):
        self.name = name

class BinaryOpNode(ASTNode):
    def __init__(self, op: str, left: ASTNode, right: ASTNode):
        self.op = op
        self.left = left
        self.right = right

class AssignNode(ASTNode):
    def __init__(self, target: str, expr: ASTNode):
        self.target = target
        self.expr = expr

class PrattParser:
    def __init__(self, tokens: List[Token]):
        self.tokens = tokens
        self.idx = 0

    def peek(self) -> Token:
        return self.tokens[self.idx]

    def consume(self, expected: Optional[TokenType] = None) -> Token:
        tok = self.peek()
        if expected and tok.typ != expected:
            raise SyntaxError(f"Expected {expected.name}, got {tok.typ.name}")
        self.idx += 1
        return tok

    def parse_prefix(self) -> ASTNode:
        tok = self.consume()
        if tok.typ == TokenType.NUMBER:
            return NumberNode(tok.value)
        if tok.typ == TokenType.IDENT:
            if self.peek().typ == TokenType.ASSIGN:
                self.consume(TokenType.ASSIGN)
                expr = self.parse_expr(rbp=1)
                return AssignNode(tok.value, expr)
            return VarNode(tok.value)
        if tok.typ == TokenType.LPAREN:
            node = self.parse_expr(rbp=0)
            self.consume(TokenType.RPAREN)
            return node
        raise SyntaxError(f"Unexpected prefix token {tok}")

    def infix_binding_power(self, typ: TokenType) -> Tuple[int, int]:
        if typ in (TokenType.PLUS, TokenType.MINUS):
            return (5, 6)
        if typ in (TokenType.STAR, TokenType.SLASH):
            return (7, 8)
        return (0, 0)

    def parse_expr(self, rbp: int = 0) -> ASTNode:
        left = self.parse_prefix()
        while True:
            cur = self.peek()
            lbp, next_rbp = self.infix_binding_power(cur.typ)
            if lbp <= rbp:
                break
            op_tok = self.consume()
            right = self.parse_expr(next_rbp)
            left = BinaryOpNode(op_tok.value, left, right)
        return left

# Opcodes
class Opcode(Enum):
    LOAD_CONST = auto()
    LOAD_FAST = auto()
    STORE_FAST = auto()
    BINARY_ADD = auto()
    BINARY_SUB = auto()
    BINARY_MUL = auto()
    BINARY_DIV = auto()
    RETURN_VALUE = auto()

class CodeObject:
    def __init__(self):
        self.bytecode: List[Tuple[Opcode, int]] = []
        self.constants: List[Any] = []
        self.varnames: List[str] = []

    def add_const(self, val: Any) -> int:
        if val in self.constants:
            return self.constants.index(val)
        idx = len(self.constants)
        self.constants.append(val)
        return idx

    def add_var(self, name: str) -> int:
        if name in self.varnames:
            return self.varnames.index(name)
        idx = len(self.varnames)
        self.varnames.append(name)
        return idx

    def emit(self, op: Opcode, arg: int = 0):
        self.bytecode.append((op, arg))

class BytecodeCompiler:
    def __init__(self):
        self.code = CodeObject()

    def compile(self, node: ASTNode):
        if isinstance(node, NumberNode):
            const_idx = self.code.add_const(node.val)
            self.code.emit(Opcode.LOAD_CONST, const_idx)
        elif isinstance(node, VarNode):
            var_idx = self.code.add_var(node.name)
            self.code.emit(Opcode.LOAD_FAST, var_idx)
        elif isinstance(node, AssignNode):
            self.compile(node.expr)
            var_idx = self.code.add_var(node.target)
            self.code.emit(Opcode.STORE_FAST, var_idx)
        elif isinstance(node, BinaryOpNode):
            self.compile(node.left)
            self.compile(node.right)
            op_map = {
                '+': Opcode.BINARY_ADD,
                '-': Opcode.BINARY_SUB,
                '*': Opcode.BINARY_MUL,
                '/': Opcode.BINARY_DIV,
            }
            self.code.emit(op_map[node.op], 0)
        else:
            raise NotImplementedError(f"Unknown AST node {type(node)}")

def run_lab():
    # 1. Lexing test
    source = "res = (x + 10) * 3 - y / 2"
    lexer = Lexer(source)
    tokens: List[Token] = []
    while True:
        tok = lexer.next_token()
        tokens.append(tok)
        if tok.typ == TokenType.EOF:
            break

    assert len(tokens) == 14
    assert tokens[0].typ == TokenType.IDENT and tokens[0].value == "res"
    assert tokens[1].typ == TokenType.ASSIGN

    # 2. Pratt Parsing test (Operator Precedence)
    parser = PrattParser(tokens)
    ast = parser.parse_expr()
    assert isinstance(ast, AssignNode)
    assert ast.target == "res"
    # Root of expression is minus: ((x + 10) * 3) - (y / 2)
    assert isinstance(ast.expr, BinaryOpNode)
    assert ast.expr.op == '-'
    assert isinstance(ast.expr.left, BinaryOpNode)
    assert ast.expr.left.op == '*'

    # 3. Bytecode Compilation test
    compiler = BytecodeCompiler()
    compiler.compile(ast)
    compiler.code.emit(Opcode.RETURN_VALUE, 0)

    # Check constants and variables
    assert compiler.code.constants == [10, 3, 2]
    assert compiler.code.varnames == ["x", "y", "res"]

    # Check linear instruction stream
    expected_ops = [
        Opcode.LOAD_FAST,    # load x
        Opcode.LOAD_CONST,   # load 10
        Opcode.BINARY_ADD,   # x + 10
        Opcode.LOAD_CONST,   # load 3
        Opcode.BINARY_MUL,   # (x + 10) * 3
        Opcode.LOAD_FAST,    # load y
        Opcode.LOAD_CONST,   # load 2
        Opcode.BINARY_DIV,   # y / 2
        Opcode.BINARY_SUB,   # ... - ...
        Opcode.STORE_FAST,   # res = ...
        Opcode.RETURN_VALUE
    ]
    actual_ops = [instr[0] for instr in compiler.code.bytecode]
    assert actual_ops == expected_ops
    print("Bytecode VM Lab 01 passed: Lexing, Pratt parsing, and code generation verified successfully.")

if __name__ == "__main__":
    run_lab()
```
